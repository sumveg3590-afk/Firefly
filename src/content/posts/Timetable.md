## 📋 你需要死盯的时间表（按届正常节奏排）

| ---------- | ------------------------------------------------------- | --------------------------------------------- |

| 2026.10-12 | 装修系统核心模块开发；把Redis用进项目里（别“空余学”）   | 日常实习全年滚动可投，随时关注                |

**产出**：苍穹外卖完成、装修系统MVP、简历初稿。


### 大二寒假（2027年1月 - 2月）

| 月份     | 必须做的事                                     | 死盯的节点                            |
| -------- | ---------------------------------------------- | ------------------------------------- |
| 2027.1-2 | 装修系统部署上线；简历定稿；继续力扣/高数/英语 | **2027年2月10日：上半年男兵报名截止** |

**提醒**：寒假实习周期太短（只有两三个月），性价比不高，不如专注把装修项目做深。


### 大二下（2027年2月 - 7月）

**主线：操作系统 + MySQL索引 + Redis；找实习；力扣/高数/英语不断**

这是你计划中**负载最重的一个学期**，必须做减法。

| 月份         | 必须做的事                                                  | 死盯的节点                                             |
| ------------ | ----------------------------------------------------------- | ------------------------------------------------------ |
| 2027.2       | 简历定稿；OS/MySQL/Redis 选1-2项深入，别全铺开              | 日常实习全年滚动可投，立刻开始投                       |
| 2027.3       | **批量投递日常实习**（牛客、Boss、实习僧、内推群）          | 每天定向投10-15家，优先选更新时间≤3天的岗位            |
| 2027.4       | 笔试 + 面试                                                 | 大厂暑期实习主要面向大三下，你这一轮以**日常实习**为主 |
| **2027.5.1** | **你的决策点：找到实习 → 准备入职；没找到 → 6月底前继续投** | 建议不要把5.1当“一刀切”，5-6月仍有第二轮机会           |
| 2027.5-6     | 若实习未定，继续投递；OS/MySQL/Redis别停                    | —                                                      |
| 2027.7       | 若找到实习，进入实习                                        | —                                                      |

**关键认知**：日常实习转正率很低（多数企业＜5%），但作为**第一段实习打底**是合适的，目的是积累真实项目经验和代码提交记录。


### 大二暑假（2027年7月 - 8月）

| 月份     | 必须做的事                                                   | 死盯的节点                            |
| -------- | ------------------------------------------------------------ | ------------------------------------- |

**提醒**：暑假前至少1-2个月就要开始投递简历，等放假才开始找就太晚了。


### 大三上（2027年9月 - 2028年1月）

**主线：考研基础启动 + 冲刺更好的暑期实习**

你的原计划是“大三全力备考考研”，但正常节奏下，大三上是**启动基础**而非冲刺。

| 月份       | 必须做的事                                             | 死盯的节点                             |
| ---------- | ------------------------------------------------------ | -------------------------------------- |
| 2027.9-10  | 考研确定目标院校和专业；英语背核心词汇；数学过教材基础 | 关注目标院校招生简章                   |
| 2027.10-12 | 每天2-3小时考研基础；**同时继续投递大三暑期实习**      | 字节全年4次投递机会，2027年1月刷新两次 |
| 2028.1     | 期末 + 寒假强化                                        | —                                      |

**关键认知**：大三上没有报考资格，正式报名和初试都在大四上学期。所以大三上**不需要全力冲刺**，边保持考研基础边把项目/实习补齐。

**主线：考研系统复习 + 暑期实习冲刺**

| 月份     | 必须做的事                                     | 死盯的节点                                           |
| -------- | ---------------------------------------------- | ---------------------------------------------------- |
| 2028.2-3 | 考研：数学刷基础题、英语真题精读、专业课第一轮 | **2028年3月：大厂暑期实习集中开放**（阿里3月18日等） |

## ⚠️ 你绝对不能错过的5个硬节点

1. **2027年2月10日**：上半年男兵报名截止（若考虑参军）
2. **2027年5月1日**：你的实习决策点（建议放宽到6月底）
3. **2027年8月10日**：下半年男兵报名截止

## 💎 和上版的区别

这版**完全按你这一届的正常考研节奏**：大三上启动基础、大三下系统复习、大三暑假强化、大四上报名初试。没有把你的考研时间提前，也没有改变你原计划的大框架，只是把容易错过的机会窗口单独拎出来了。
